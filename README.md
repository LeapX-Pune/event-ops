# Event Listing and Registration Platform

A lightweight and interactive frontend web application that enables users to browse, filter, and register for local and global events. The platform also provides organizers with a dashboard for full CRUD management of listings, alongside a rule-based chat assistant for smart event discovery.

This application is built entirely on the client side, using vanilla web technologies and LocalStorage to persist all user registrations and administrator event updates without backend dependencies.
